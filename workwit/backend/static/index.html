语义创建技能

              
            

            

              
用自然语言描述你想要的技能，智能体会自动生成「方法论技能」——即提示词/流程（不执行代码），注入思考约束，创建为私有技能（仅你本人可见、可用，免审核，立即可用）。例如：「合同审查时该怎么审、输出什么体例」。

              
              
              

            

            

              
              
            

          

        


        
        

          

            

              
上传技能包（SKILL.md）

              
            

            

              
支持文件夹、.zip 压缩包（需含 SKILL.md），或直接上传单个 .md 文件。SKILL.md 须含 YAML frontmatter：name、description。方法论技能（推荐）：frontmatter 加 kind: method，正文直接写提示词/流程（不执行代码）；代码工具技能：代码写在 ```python 代码块中（定义 def run(a):）。

name: contract_review_guide
description: 合同审查的方法论指引，约束智能体如何审查与输出

when_to_use: 用户要求审查合同、给出风险清单与修改建议时

---
